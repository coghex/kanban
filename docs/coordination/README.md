# Coordination notes

Free-form coordination material: notes, roadmap sketches, and other
non-authoritative records the pipeline coordinates around, none of which any
runtime, installer, or test reads. Every tracked Markdown file in this
directory takes the `coordination` publication lane and stays out of the
source distribution, with no per-file declaration anywhere.

The authoritative policy — what belongs here, how it publishes, and the
whole-component matching that scopes this directory — is
[docs/agent-workflow-contract.md §7](../agent-workflow-contract.md#7-document-publication-classification);
this README deliberately does not restate it.
